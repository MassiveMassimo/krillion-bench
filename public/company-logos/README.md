# Decorative company marks

These 22 marks are from [Lobe Icons](https://github.com/lobehub/lobe-icons), pinned to commit `c385b2b8d1f9e19aa86e628d4e23c91ee1111a47`. Each source file is `packages/static-svg/icons/<id>.svg`. The upstream MIT license is retained in `LICENSE`. Company names and marks remain their owners' trademarks. These decorations do not imply endorsement or benchmark participation.

The set includes AI21 Labs, Alibaba, Anthropic, Apple, Baidu, Cohere, DeepSeek, Google, Hugging Face, IBM, Meta, Microsoft, MiniMax, Mistral AI, Moonshot AI, NVIDIA, OpenAI, Stability AI, Tencent, Together AI, xAI, and Z.ai.

Include developers with published text-language model families. Exclude speech/video-only entries, inference-only platforms, and entries verified only through adaptations of another developer's base model. This follows the approved 22-company selection, not a claim that every company currently focuses on LLMs. Less obvious qualifying releases include [Apple OpenELM](https://machinelearning.apple.com/research/openelm), [Hugging Face SmolLM](https://huggingface.co/HuggingFaceTB/SmolLM2-1.7B), [Together AI StripedHyena](https://huggingface.co/togethercomputer/StripedHyena-Hessian-7B), and [Stability AI StableLM](https://stability.ai/news-updates/introducing-stable-lm-2).

Normalization changes only the SVG viewBox. Each original glyph was rendered at 256 × 256 pixels. Its alpha bounds above 16/255 were measured, centered in a square, and padded by 12%. This preserves the original path geometry and aspect ratio. An 18px CSS mask yields about 16px visible extent. All glyphs use the same monochrome ocean treatment. No logo package or runtime CDN is required.

Source example: [DeepSeek SVG at the pinned revision](https://github.com/lobehub/lobe-icons/blob/c385b2b8d1f9e19aa86e628d4e23c91ee1111a47/packages/static-svg/icons/deepseek.svg).
